# Code intelligence availability

The project may expose Serena over MCP with Intelephense. Tool configuration is only
evidence that a server can be started; inspect the active tool list before relying on it.

If Serena is available, use symbol references for signature, port, DTO, enum and
constant changes. The free Intelephense implementation can return incomplete results
while a cold index warms and does not reliably implement every navigation operation.
Repeat a suspiciously empty reference query once, then compare with `rg`.

If the MCP is unavailable, continue with repository search, PHPStan, Deptrac and tests.
Report the fallback. Do not claim that an empty text search proves a symbol has no
consumers when namespaces, aliases or generated metadata can hide the relationship.
